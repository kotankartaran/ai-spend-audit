# Product Metrics

## Core Metrics

### Monthly Active Users (MAU)

Tracks recurring platform usage.

### Audit Completion Rate

Measures how many users complete audits.

### Average Estimated Savings

Measures average identified optimization opportunities.

### Share Rate

Tracks how often users share audit reports.

### Conversion Rate

Measures free-to-paid conversion for future premium plans.

## Technical Metrics

- API response time
- Database insertion success rate
- Deployment uptime
- Error rates

## Growth Metrics

- GitHub stars
- Product Hunt traffic
- Referral traffic
- Organic acquisition
