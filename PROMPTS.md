# AI Prompt Ideas

Future versions of the platform may use AI-generated optimization summaries.

## Example Prompt

"Analyze this company's AI subscription spending and generate cost optimization recommendations based on tool overlap, inactive seats, and team size."

## Example Inputs

- Tool names
- Team size
- Monthly spend
- Current subscription plans

## Example Outputs

- Cost reduction opportunities
- Plan downgrade recommendations
- Seat optimization suggestions
- Annual savings estimation
